## Telegram-pay-bot

## You can pay or buy things in it, in bots. 

## 🐍 Project write on Python and have open source.

## You can edit the code yourself and customize it however you want.

## How to install and runnig?

### 1. Clone project
```
git clone https://github.com/tuxarith/Telegram-Pay-bot.git
```
### 2. Go to the directory
```
cd Telegram-Pay-bot
```
### 3. Create file in the project root
### file example_token-bot.env - this is a example for file token-bot.env!!!
```
token-bot.env
```
### 4. add this inside
```
TOKEN = your_token_bot
```
### You can get token from @BotFather

### 5. Run the bot
```
python3 main.py
```

## Установка и Запуск
### 1. Скопируйте проект:
````bash
git clone https://github.com/tuxarith/Telegram-Pay-bot.git
````
### 2. Зайдите в директорию проекта:
````bash
cd Telegram-Pay-bot
````
### 3. Установите зависимости:
````bash
pip install -r requirements.txt
````

### 4. Создайте файлы в корне проекта:

### Файл `example_bot-token.env` - просто шаблон для файла `bot-token.env`  !!!

```bash
bot-token.env
```
### Пропишите в нем:
```bash
TOKEN=ваш_телеграм_бот_токен
```

### Токен можно получить у @BotFather.

### 5. Запустите бота:
````bash
python3 main.py
````
